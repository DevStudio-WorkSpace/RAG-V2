Estado 2 — Sin resultados (respuesta vacía controlada)
------------------------------------------------------
- Hallazgo del motor: con las imágenes de prueba el motor **no** devolvió 0
  resultados. La normalización min-max del score de embeddings asigna 1.0 al
  mejor candidato y el embedding pesa 0.50 del score final, por lo que el piso
  del score es ~0.50; el umbral absoluto `UMBRAL_MINIMO_SIMILARIDAD = 0.40`
  nunca filtra mientras Qdrant devuelva candidatos. Probado con una imagen
  sintética sin prenda, una captura de UI y sólidos negro/blanco y ruido:
  todas devolvieron entre 1 y 5 resultados (scores 0.50–0.83).
- Por eso el estado se verificó con un upstream controlado que responde
  exactamente el contrato de la API cuando no hay coincidencias:
  `200 {"resultados": [], "modo": "auto", "modelo": "clip"}`.
- Observado en el navegador:
  - «Sin resultados para esta imagen» con explicación del umbral y sugerencias.
  - Botones «Reintentar búsqueda» y «Probar con otra imagen».
  - Sin encabezado «Modelos Coincidentes Encontrados» ni tarjetas.
- Evidencia: `frontend-sin-resultados-2026-11-13.png` y `.txt`.

Reproducción del upstream controlado
------------------------------------
Script usado (Node, escucha en 8100; `STUB_MODE=empty|hang`):

```js
const http = require("http");
const mode = process.env.STUB_MODE || "empty";
http.createServer((req, res) => {
  if (req.method === "POST" && req.url.startsWith("/search/image")) {
    req.resume();
    if (mode === "hang") return; // dispara el timeout del proxy
    req.on("end", () => setTimeout(() => {
      res.writeHead(200, { "Content-Type": "application/json" });
      res.end(JSON.stringify({ resultados: [], modo: "auto", modelo: "clip" }));
    }, 300));
    return;
  }
  res.writeHead(404); res.end("{}");
}).listen(8100, "127.0.0.1");
```

Con `API_URL=http://127.0.0.1:8100` y `API_CLIENT_KEY` cualquiera en el
frontend. Para el caso de tiempo agotado se usó `STUB_MODE=hang` y
`SEARCH_TIMEOUT_MS=3000` durante el desarrollo del estado.
